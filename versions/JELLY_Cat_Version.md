# JELLY ICON — CAT VERSION GUIDE

## Purpose

Use this file **only** for pet supplies made for cats, or when the request names a cat (고양이, 냥이, 캣).

Read `style/JELLY_Style_Lock.md` first. That universal style lock always has higher priority. This file only sets the colors, motif, and glow; it does not change the material, lighting, composition, or form language.

Use `references/cat/` as the visual source of truth whenever the images are attached.

---

## Cat identifiers

### Colors

- main body: hot pink `#FF4081`
- secondary parts: light pink `#FFC1D6`
- small accents: white
- no teal anywhere

### Paw motif

- exactly one small hot pink paw print: four oval toe beans and one rounded main pad
- slightly embossed on the main front face, centered
- about 15–20% of the object width
- keeps the same shape, position, and orientation in every view

Do not use a bone, fish, or cat-face motif, or more than one paw.

### Glow

- soft pink glow reflection under the object

---

```
Main body hot pink (#FF4081), secondary light pink (#FFC1D6), small white accents. No teal anywhere.

```

Glow color: `pink`

---

## When not to use this file

Do not use this version for dog-only supplies (leash, treat ball, dog bed) unless the request explicitly asks for a cat version, or for service icons (coupon, cart, delivery, notification). Use `JELLY_Common_Version.md` for those.

Element name: `{object}_고양이`
