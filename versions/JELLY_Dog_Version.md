# JELLY ICON — DOG VERSION GUIDE

## Purpose

Use this file **only** for pet supplies made for dogs, or when the request names a dog (강아지, 댕댕이, 개).

Read `style/JELLY_Style_Lock.md` first. That universal style lock always has higher priority. This file only sets the colors, motif, and glow; it does not change the material, lighting, composition, or form language.

Use `references/dog/` as the visual source of truth whenever the images are attached.

---

## Dog identifiers

### Colors

- main body: deep teal `#338083`
- secondary parts: mint aqua `#8ED8D4`
- small accents: white
- no pink anywhere

### Bone motif

- exactly one small white dog bone shape
- slightly embossed on the main front face, centered, horizontal
- about 15–20% of the object width
- keeps the same shape, position, and orientation in every view

Do not use a paw print, dog-face, or ball motif, or more than one bone.

### Glow

- soft teal glow reflection under the object

## When not to use this file

Do not use this version for cat-only supplies (litter box, cat tower, wand toy) unless the request explicitly asks for a dog version, or for service icons (coupon, cart, delivery, notification). Use `JELLY_Common_Version.md` for those.

Element name: `{object}_강아지`
