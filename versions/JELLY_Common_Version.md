# JELLY ICON — COMMON VERSION GUIDE

## Purpose

Use this file for service icons that are not tied to a species: shopping, benefits, payment, delivery, notifications, schedule, and general pet symbols. Also use it when the request says 공통 or 서비스.

Read `style/JELLY_Style_Lock.md` first. That universal style lock always has higher priority. This file only sets the colors, motif, and glow; it does not change the material, lighting, composition, or form language.

Use `references/common/` as the visual source of truth whenever the images are attached.

---

## Common identifiers

### Colors

- main body: hot pink `#FF4081`
- secondary parts: light pink `#FFC1D6`
- accent parts: a small amount of deep teal `#338083` (a card, a knob, bells, wheels)
- details: white

### Motif

- none by default
- a small heart is allowed when it suits the object
- one small paw print is allowed only when the object needs a pet-service hint (e.g. wallet)
- never a bone

### Color exceptions

Only these objects keep their real-world color as the main body:

- parcel box: kraft brown cardboard
- point coin: gold

### Glow

- soft pink glow reflection under the object

## When not to use this file

Do not use this version for species-specific pet supplies (food, bowls, toys, grooming, beds, carriers, litter). Ask whether it is for a dog or a cat if the request does not say.

Element name: `{object}` (no suffix)
